Arduino UNO · 신호등 · 4핀 버튼 · 2핀 부저

아두이노 신호등 프로젝트

배선 방법, 동작 설명, 통합 코드 및 브라우저 시뮬레이션을 한 파일에 정리했습니다.

1. 최종 동작

전원 연결 시 빨간불 유지 + 멜로디 반복 → 버튼 누르면 노란불 3초(음악 정지) → 초록불 유지 → 다시 버튼 누르면 노란불 3초 → 빨간불 유지 + 멜로디 재시작 순서입니다.

노란불이 켜진 3초 동안의 버튼 입력은 무시합니다.

2. 신호등 시뮬레이션

빨간불 유지 · 멜로디 재생 상태

버튼을 눌러 전환하세요.

브라우저 시뮬레이션은 실제 부저 소리를 재생하지 않습니다.

3. UNO 핀 연결표

부품아두이노 핀
신호등 G (초록)D10
신호등 Y (노랑)D9
신호등 R (빨강)D8
신호등 GNDGND
4핀 버튼 한쪽D2
4핀 버튼 반대쪽GND
2핀 부저 (+)D7
2핀 부저 (-)GND

4핀 택트 버튼은 같은 쪽 다리끼리 내부적으로 연결된 형태가 일반적입니다. 버튼을 눌렀을 때만 D2와 GND가 연결되도록 반대편 다리끼리 연결하세요. GND가 부족하면 브레드보드의 공통 (-) 레일에 UNO GND를 연결한 후 여러 부품의 GND를 함께 연결합니다.

배선 변경 시 USB 전원을 분리하세요. 부저는 소형 수동형이며 D7 핀의 허용 전류 내에서 구동 가능한 제품을 가정합니다. 능동형 또는 고전류 부저는 별도 구동 회로가 필요할 수 있습니다.

4. 통합 아두이노 코드

아두이노 IDE에 아래 코드를 붙여넣고 보드/포트를 선택해 업로드하세요. 멜로디는 엘리니아 원곡이 아닌 분위기를 참고한 시험용 멜로디입니다.

const int RED = 8;
const int YELLOW = 9;
const int GREEN = 10;
const int BUTTON = 2;
const int BUZZER = 7;

// 엘리니아 분위기의 시험용 멜로디 (원곡 아님)
const int melody[] = {
  659, 784, 880, 784,
  659, 587, 523, 587,
  659, 784, 988, 880,
  784, 659, 587, 523,
  587, 659, 784, 659,
  587, 523, 440, 523,
  587, 659, 587, 523,
  494, 523, 587, 523
};
const int durations[] = {
  300, 300, 600, 300,
  300, 300, 600, 300,
  300, 300, 600, 300,
  300, 300, 600, 300,
  300, 300, 600, 300,
  300, 300, 600, 300,
  300, 300, 600, 300,
  300, 300, 600, 700
};
const int noteCount = sizeof(melody) / sizeof(melody[0]);

bool greenMode = false;
bool changing = false;
bool lastReading = HIGH;
bool stableButton = HIGH;
unsigned long debounceTime = 0;
unsigned long yellowStart = 0;
unsigned long noteStart = 0;
int noteIndex = 0;
bool noteStarted = false;

void setLights(bool red, bool yellow, bool green) {
  digitalWrite(RED, red);
  digitalWrite(YELLOW, yellow);
  digitalWrite(GREEN, green);
}
void stopMusic() {
  noTone(BUZZER);
  noteIndex = 0;
  noteStarted = false;
}
void playMusic() {
  unsigned long now = millis();
  if (!noteStarted) {
    tone(BUZZER, melody[noteIndex]);
    noteStart = now;
    noteStarted = true;
  }
  unsigned long elapsed = now - noteStart;
  if (elapsed >= durations[noteIndex] * 85UL / 100UL) {
    noTone(BUZZER);
  }
  if (elapsed >= (unsigned long)durations[noteIndex]) {
    noteIndex++;
    if (noteIndex >= noteCount) noteIndex = 0;
    noteStarted = false;
  }
}
void setup() {
  pinMode(RED, OUTPUT);
  pinMode(YELLOW, OUTPUT);
  pinMode(GREEN, OUTPUT);
  pinMode(BUTTON, INPUT_PULLUP);
  pinMode(BUZZER, OUTPUT);
  setLights(HIGH, LOW, LOW);
}
void loop() {
  bool reading = digitalRead(BUTTON);
  if (reading != lastReading) debounceTime = millis();
  if (millis() - debounceTime > 50) {
    if (reading != stableButton) {
      stableButton = reading;
      if (stableButton == LOW && !changing) {
        changing = true;
        yellowStart = millis();
        stopMusic();
        setLights(LOW, HIGH, LOW);
      }
    }
  }
  lastReading = reading;
  if (changing && millis() - yellowStart >= 3000UL) {
    changing = false;
    greenMode = !greenMode;
    if (greenMode) {
      setLights(LOW, LOW, HIGH);
    } else {
      setLights(HIGH, LOW, LOW);
      stopMusic();
    }
  }
  if (!greenMode && !changing) playMusic();
}

5. 문제 해결

버튼을 눌러도 빨간불만 켜질 때: D2와 GND가 버튼을 누를 때 연결되는지 확인하세요. 테스트 시 D2를 GND에 잠깐 접촉시켰다가 떼면 버튼을 누른 것과 같은 효과가 납니다.

부저 소리가 안 날 때: (+)/(-) 방향, D7 연결, 부저 종류(수동형/능동형)와 정격 전류를 확인하세요.

GND가 모자랄 때: UNO GND를 브레드보드 (-) 레일에 연결해 공통 접지로 사용하세요.

음악이 원곡과 다를 때: 현재 코드는 원곡이 아닌 시험용 멜로디입니다. 정확한 곡을 재현하려면 악보나 MIDI에 맞춰 음을 다시 입력해야 합니다.
